# Открытие листа, загрузка карты и музыка

Триггеры находятся в категории **Events / События**, музыкальные ноды —
в **Music / Музыка**. После обновления файлов системы перезагрузите клиент Foundry.

## On Sheet Open — При открытии листа

Добавьте ноду в **Sheet Blueprint / граф триггеров листа** персонажа или предмета.
Поле **Sheet UUID / self** принимает:

- `self` — открытие листа документа, которому принадлежит граф;
- конкретный UUID, например `Actor.abc123` или `Item.def456` — открытие этого документа.

Событие выполняется на клиенте пользователя, открывшего лист. Оно срабатывает
один раз на открытие окна. Изменение полей и повторный рендер не запускают его снова;
закрытие и повторное открытие запускают. `self` у предмета означает лист самого
предмета, а не лист персонажа, в инвентаре которого он находится.

Выходы: **Opened UUID**, **Name**, **Document Type**, **User ID**. Для листа
независимого токена UUID выхода относится к его синтетическому документу;
`self` в графе исходного персонажа также распознаёт это открытие.

Пример: `On Sheet Open (self)` → `Show 3D Model`.
Другой пример: `On Sheet Open (self)` → `Play Music` с каналом `sheet-theme`.
Закрытие листа само по себе не останавливает музыку: для остановки подключите
`Stop Music` к отдельной кнопке.

## On Map Loaded — При загрузке карты

**Scene** выбирает сцену Foundry. Пустое значение означает любую сцену.
**Scene UUID / ID override** позволяет вручную задать UUID или ID и имеет
приоритет над выбором в списке. Имя сцены фильтром не является.

Событие запускается после готовности canvas, включая начальную загрузку мира.
Повторное уведомление о той же готовой сцене игнорируется; выгрузка и новая
загрузка canvas снова запускают событие.

Режимы **Run on**:

- **Current client** — выполнение у пользователя, на клиенте которого загрузилась карта;
- **Active GM only** — выполнение только у одного активного ведущего, когда карта
  загрузилась на его клиенте. Загрузка карты только у игрока не вызывает событие у ведущего.

Выходы: **Scene UUID**, **Scene ID**, **Scene Name**, **User ID**.
Граф можно хранить в отдельном мировом предмете: для этих двух триггеров не требуется
флаг `outOfSheet`. Чтобы общий плейлист не запускался несколько раз, храните
управляющий граф в одном документе, а не в копии на каждом персонаже.

Пример: `On Map Loaded (Нужная сцена, Active GM only)` → `Play Playlist`.

## Музыкальные ноды

| Нода | Что делает |
| --- | --- |
| Play Music | Локально воспроизводит файл по пути/HTTP(S)-адресу; громкость, повтор, плавное начало |
| Pause Music | Приостанавливает локальный канал с сохранением позиции |
| Resume Music | Продолжает локальный канал с места паузы |
| Stop Music | Останавливает локальный канал; возможно плавное затухание |
| Music Volume | Меняет громкость локального канала, в том числе плавно |
| Play Playlist | Запускает общий плейлист Foundry или выбранный трек |
| Control Playlist | Пауза, продолжение, остановка, следующий/предыдущий трек общего плейлиста |
| Playlist Volume | Меняет сохранённую громкость одного или всех треков плейлиста |

У локальной музыки **Channel ID** по умолчанию `music`. Повторный `Play Music`
на том же канале заменяет предыдущий трек; разные каналы играют одновременно.
Передавайте выход Channel ID в следующие ноды. Путь — например
`worlds/my-world/audio/theme.ogg`. Поддержка формата зависит от браузера.
Громкость задаётся от 0 до 1, **Fade** — в миллисекундах, от 0 до 60000.
Остановка уже отсутствующего канала считается успешной.

Плейлист и трек можно выбрать в списках или передать их UUID/ID входными проводами.
Пустой трек означает весь выбранный плейлист. Следующий/предыдущий трек работают
в последовательном и случайном режимах воспроизведения. Пауза сохраняет текущую
позицию треков; продолжение запускает только поставленные на паузу треки.

Общие плейлисты используют стандартные изменения документов Foundry и требуют
права обновлять плейлист (обычно это ведущий). Ноды не повышают права игрока и
не отправляют запросы на выполнение от имени ведущего. Локальная музыка доступна
на клиенте самого пользователя и использует музыкальный аудиоканал Foundry.
Браузер может потребовать первый клик пользователя для разблокировки аудио.

У всех музыкальных нод есть **Then**, **Success**, **Error**. Then продолжается
после действия и при ошибке; используйте Success с ветвлением. Ошибка загрузки,
неверный трек или отсутствие прав вернут `false` и описание ошибки. Локальная
загрузка ограничена 60 секундами; Stop Music отменяет ожидание и не позволяет
поздно загрузившемуся файлу начать играть.

## Проверки и API

`node scripts/test-lifecycle-music.mjs` проверяет компиляцию и фактический
исполнитель графа, фильтры и жизненный цикл событий, локальные каналы,
отмену загрузки, операции плейлистов и отказ в правах. Foundry hooks, Sound и
Playlist заменены тестовыми объектами; проверку звука и окон в живом мире v14
нужно выполнить в установленном Foundry.

Использованы официальные API v14:
[renderApplicationV2](https://foundryvtt.com/api/functions/hookEvents.renderApplicationV2.html),
[canvasReady](https://foundryvtt.com/api/functions/hookEvents.canvasReady.html),
[Sound](https://foundryvtt.com/api/classes/foundry.audio.Sound.html),
[Playlist](https://foundryvtt.com/api/classes/foundry.documents.Playlist.html).
