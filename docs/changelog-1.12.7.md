# System Director 1.12.7 — оптимизация нодного графа

Совместимость: Foundry VTT v14. Все изменения 1.12.6 сохранены.

## Изменения
- Соединения больше не удаляются и не создаются заново при каждом движении мыши: используются постоянные SVG-элементы.
- Геометрия пинов измеряется пакетно и кэшируется в координатах графа. В прогретом цикле панорамирования нет повторного измерения каждого пина.
- Ноды и пины индексируются; отрисовка не ищет каждую исходную ноду полным перебором массива.
- Перемещение, зум, перетаскивание нод и предпросмотр соединения объединяются в один кадр браузера.
- Изменения положения не запускают компиляцию формулы и перестроение панели переменных.
- Ноды и соединения вне видимой области не рисуются. Их значения, поля и модель сохраняются; обратные и пересекающие экран кривые учитываются.
- Убрано создание отдельного графического слоя для каждой ноды; ограничена область её перерасчёта.
- Кэш обновляется при динамических пинах, замене DOM, Undo/Redo, изменении размеров, CSS и шрифтов, переносе окна в другой Document.
- Закрытие редактора отменяет кадры и таймеры, отсоединяет наблюдателей и освобождает кэш.
- В старом тесте Roll Result убрана привязка к конкретной версии 1.12.0; проверки поведения сохранены.

Формат сохранённых графов не менялся. Пересоздавать графы не нужно.

## Установка
1. Сделайте резервную копию мира и прежней папки системы.
2. Остановите мир/Foundry, замените папку sd в Data/systems папкой из архива.
3. Запустите Foundry и обновите клиент через Ctrl+Shift+R.
4. Проверьте версию 1.12.7 и откройте существующий большой граф.
