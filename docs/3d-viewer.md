# 3D-ноды / 3D nodes

В библиотеке графа появилась категория **3D-объекты / 3D Objects**.
Окна открываются только у пользователя, который выполняет граф. Это просмотрщик
моделей в окне, а не размещение 3D-токенов на сцене Foundry.

## Быстрый запуск

1. Подключите выход выполнения события кнопки к **Показать 3D-фигуру**.
2. Выберите куб, сферу, цилиндр или тор. Сохраните граф и нажмите кнопку.
3. В окне: ЛКМ — вращение камеры вокруг модели, колесо — приближение,
   ПКМ — перемещение камеры. Есть сброс камеры, автовращение и каркас.
4. Для своего файла используйте **Показать 3D-модель** и путь вроде
   `worlds/my-world/models/sword.glb`. Рядом с путём есть файловый пикер; ручной ввод и вход «Путь модели» тоже доступны.

## Свои интерактивные точки

1. В графе укажите файл или фигуру в ноде показа.
2. Нажмите **Задать точки** непосредственно в ноде. Откроется отдельный редактор модели.
3. Введите уникальный **Point ID** (например, `door`) и текст подсказки.
4. Нажмите **Задать точку**, затем **ЛКМ по поверхности модели**. Координаты определятся автоматически. Режим размещения выключится после одного клика.
5. Для другой точки введите другой ID и повторите размещение. Повторное размещение того же ID перемещает существующую точку.
6. Выберите точку в списке, измените текст и нажмите **Изменить точку**; **Удалить точку** удаляет выбранную.
7. Нажмите **Сохранить точки** — данные попадут в ноду. Затем сохраните сам граф. Повторное открытие редактора восстановит точки, включая пустой список после удаления всех точек.

При выполнении ноды открывается просмотр **без редактора точек**. Можно вращать модель, нажимать точки и читать подсказки; добавление, перемещение, изменение и удаление точек доступны только в редакторе из графа. Редактор не запускает игровые события. Старые точки из флагов документа доступны для переноса: откройте редактор и сохраните их в ноду.

## Exec-выходы для каждой точки

Соедините **Далее** ноды показа со входом Exec ноды **События точек 3D / 3D Point Events**, а **Массив точек** — с её входом Points. Из сохранённых в ноде показа точек автоматически появятся отдельные Exec-выходы. Выберите `click`, `hover` или `leave` и подключите действия к нужной точке. Выход **Готово** выполняется сразу после привязки событий; выходы точек — при взаимодействии. Изменение подписи точки сохраняет соединения, изменение её ID требует переподключения. При повторном открытии окна цепочка должна вновь пройти через ноду событий.

Альтернатива: **При взаимодействии с 3D / On 3D Interaction** в Sheet Blueprint того же документа. Укажите ID окна и ID точки, выберите событие. Пустой ID точки принимает события модели и всех точек. Выходы передают ID, текст, имя объекта и координаты.

## On Hover и всплывающие сообщения

**On Hover** срабатывает при входе курсора в выбранный виджет листа/HUD. Вместо селектора можно подключить вход **Объект**: Widget Key, UUID/ID объекта карты, выход **3D-объект** или **Массив точек** ноды показа. Подключённый вход имеет приоритет над селектором. Движение внутри объекта не повторяет событие; повторный вход запускает его снова. Объект должен иметь представление с событием наведения: произвольное число или обычные данные такого события не создают.

Для объектов карты используются штатные [события наведения Foundry v14](https://foundryvtt.com/api/functions/hookEvents.hoverObject.html).

**Всплывающее сообщение / Popup Message** показывает текст локально у текущего пользователя: у курсора, по центру или справа сверху. Настраиваются заголовок, текст и время (0 — до закрытия кнопкой). Например: **On Hover → Всплывающее сообщение** или Exec конкретной 3D-точки → сообщение.

**На весь экран** разворачивает просмотр поверх Foundry; Escape возвращает окно. Ползунок **Фон** меняет непрозрачность: 0 — прозрачный, 1 — сплошной. Эти параметры также доступны в ноде открытия и **Настройки показа 3D**.

## Ноды

| Русское название | English / type | Назначение |
| --- | --- | --- |
| Показать 3D-модель | Show 3D Model / `model3d_open` | Загружает GLB или glTF в изменяемое по размеру окно |
| Показать 3D-фигуру | Show 3D Primitive / `model3d_primitive` | Куб, сфера, цилиндр или тор; цвет и фон |
| Трансформация 3D-модели | Transform 3D Model / `model3d_transform` | Абсолютные X/Y/Z, повороты в градусах, единый положительный масштаб |
| Анимация 3D-модели | Control 3D Animation / `model3d_animation` | Запуск, пауза, остановка встроенного клипа; имя/индекс с нуля, скорость |
| Сброс 3D-камеры | Reset 3D Camera / `model3d_reset` | Вписывает всю модель в окно после трансформации |
| Закрыть 3D-окно | Close 3D Viewer / `model3d_close` | Закрывает окно и освобождает GPU-ресурсы |
| Задать точку 3D | Set 3D Point / `model3d_hotspot` | Создать, обновить или удалить точку из графа |
| Настройки показа 3D | 3D Display Settings / `model3d_display` | Полноэкранный режим и непрозрачность |
| События точек 3D | 3D Point Events / `model3d_point_events` | Массив точек → отдельные Exec-выходы по клику/наведению/уходу |
| При взаимодействии с 3D | On 3D Interaction / `on_model3d_interaction` | События клика, наведения и ухода |
| On Hover | `on_hover` | Наведение на виджет либо объект через вход |
| Всплывающее сообщение | Popup Message / `popup_message` | Локальное сообщение с текстом и временем показа |

**ID окна** по умолчанию `model`. Одинаковый ID заменяет предыдущее окно,
разные ID позволяют открыть несколько моделей. Передавайте выход ID первой ноды
во вход ID следующих. В управляющих 3D-нодах есть «Далее», «Успех» и «Ошибка».
«Далее» выполняется после завершения действия, в том числе при ошибке;
для обработки ошибок подключайте «Успех» к условию ветвления.
Закрытие уже закрытого окна считается успешным.

Пример цепочки: событие → Показать 3D-модель → Трансформация 3D-модели
(поворот Y = 45) → Сброс 3D-камеры. Соедините также выходы/входы ID окна.
Трансформация задаёт все параметры: пропущенные координаты/углы равны нулю,
масштаб равен единице. Чтобы сохранить другие параметры, указывайте их явно.

## Форматы и ограничения

- Поддерживаются обычные `.glb` и `.gltf`, материалы, текстуры и встроенные анимации.
  Кнопки выбора/паузы анимации появляются только у моделей с клипами.
- Рекомендуется GLB со встроенными текстурами. Для glTF сохраняйте относительное
  расположение `.bin` и текстур. Файлы должны уже находиться в доступном каталоге
  Foundry; просмотрщик не загружает их с компьютера на сервер.
- Внешние HTTP(S)-адреса должны разрешать CORS. На HTTPS-сервере используйте HTTPS.
- Draco, Meshopt и KTX2/Basis требуют дополнительных декодеров, которые здесь
  не подключены. Экспортируйте модель без этих вариантов сжатия. OBJ/FBX не поддерживаются.
- Нужен браузер с WebGL2. Окно остаётся внутри Foundry и не открепляется
  в отдельное окно браузера. При потере графического контекста откройте просмотр заново.
- Three.js 0.180.0 включён локально с лицензией MIT и загружается только при
  первом открытии просмотра. Интернет для самого движка не нужен.
- Загрузка ограничена 60 секундами. Закрытие отменяет ожидание; если сетевой запрос
  завершится позже, полученные ресурсы будут освобождены.

Интеграция использует существующий `SDFoundryWindowHost` на основе
[ApplicationV2 Foundry v14](https://foundryvtt.com/api/classes/foundry.applications.api.ApplicationV2.html),
[GLTFLoader](https://threejs.org/docs/pages/GLTFLoader.html) и
[OrbitControls](https://threejs.org/docs/pages/OrbitControls.html).

## Виджет 3D Object

Добавьте **3D Object** из палитры виджетов на лист персонажа, предмета или в Action HUD.
В настройках выберите файл `.glb`/`.gltf` через кнопку папки, высоту просмотра,
фон и его непрозрачность (0–1). Модель можно вращать ЛКМ, приближать колёсиком,
перемещать ПКМ и разворачивать на весь экран; Escape возвращает её на лист.

**Задать точки** открывает отдельный редактор: укажите ID и подсказку, нажмите
«Задать точку», затем ЛКМ по поверхности модели. Нажмите «Сохранить точки» и
сохраните настройки виджета. В обычном просмотре точки доступны только для
наведения и нажатия; события обрабатываются Sheet Blueprint, как у 3D-просмотра.

При включённом **Preview mode** до наведения отображается выбранная картинка.
Модель и WebGL загружаются только при наведении или фокусе с клавиатуры.
Если картинка не выбрана, сохранение точек создаёт её из текущего ракурса редактора.
После ухода курсора остаётся последний кадр, а ресурсы 3D освобождаются.
До первого просмотра без выбранной картинки отображается значок куба.

У каждой точки в редакторе есть **Show If** — формула видимости, например
`{system.level} > 2`. Пустое условие показывает точку всегда. После изменения
нажмите «Изменить точку» и «Сохранить точки». При просмотре условия проверяются
повторно, скрытые точки не показывают подсказки и не исполняют события.
В редакторе точки остаются видимыми для настройки.

**Get 3D Object** создаёт отдельные выходы для каждой сохранённой точки:
объект точки, текст, X/Y/Z и Visible. Объект содержит ID, координаты,
Show If и ссылку на виджет. Массив всех точек также остаётся доступным.
Изменение подписи сохраняет соединения; смена ID создаёт новые пины.

**On 3D Point Action / Действие точки 3D** выбирается в категории 3D
или в меню перетаскивания 3D-виджета из списка Sheet Widgets. Выберите виджет,
точку и Hover/Click, либо соедините выход конкретной точки из Get с входом
«Точка». Подключённый вход имеет приоритет над выбором в полях. Exec запускает
действия, остальные выходы передают точку, её ID, текст и координаты события.

## Проверки виджета и просмотра

`node scripts/test-3d-nodes.mjs` — компиляция графа, передача результатов,
выполнение действий, ошибки и освобождение ресурсов.

`node scripts/test-model-interactions.mjs` — загрузка точек и выполнение событий.

`node scripts/test-point-hover-graph.mjs` — сохранение/повторное открытие редактора, массивы точек, Exec-ветки, On Hover, ссылки на объекты.

`node scripts/test-3d-widget-point-nodes.mjs` — отдельные Get-пины точек, Hover/Click, Show If и фильтрация по виджету.

`node scripts/run-3d-viewer-browser.mjs` — реальный WebGL, размещение точек мышью, подсказки, клики, редактирование, сохранение, удаление, полный экран и прозрачность.

`scripts/test-3d-viewer-browser.html` — браузерная проверка с настоящим Three.js/WebGL
и облегчённой оболочкой ApplicationV2. Запускается через локальный HTTP-сервер;
она не заменяет проверку в игровом мире Foundry v14.
