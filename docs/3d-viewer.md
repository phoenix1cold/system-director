# 3D-ноды / 3D nodes

В библиотеке графа появилась категория **3D-объекты / 3D Objects**.
Окна открываются только у пользователя, который выполняет граф. Это просмотрщик
моделей в окне, а не размещение 3D-токенов на сцене Foundry.

## Быстрый запуск

1. Подключите выход выполнения события кнопки к **Показать 3D-фигуру**.
2. Выберите куб, сферу, цилиндр или тор. Сохраните граф и нажмите кнопку.
3. В окне: ЛКМ — вращение камеры вокруг модели, колесо — приближение,
   ПКМ — перемещение камеры. Есть сброс камеры, автовращение и каркас.
4. Для своего файла используйте **Показать 3D-модель** и путь вроде
   `worlds/my-world/models/sword.glb`. Рядом с путём есть файловый пикер; ручной ввод и вход «Путь модели» тоже доступны.

## Свои интерактивные точки

1. Откройте модель через ноду в Blueprint своего персонажа или предмета.
2. Разверните **Редактор интерактивных точек** в окне просмотра.
3. Введите уникальный **Point ID** (например, `door`) и текст подсказки.
4. Нажмите **Разместить точку**, затем нажмите на поверхность модели. Координаты определятся автоматически.
5. Для другой точки введите другой ID и повторите размещение. Повторное размещение того же ID перемещает существующую точку.
6. Выберите точку в списке, измените текст и нажмите **Изменить точку**; **Удалить точку** удаляет выбранную.
7. Нажмите **Сохранить точки**. Владелец документа/GM сохраняет точки в документе с привязкой к ноде открытия; при следующем выполнении этой ноды они загрузятся снова. При прямом открытии через API без документа доступен экспорт JSON.

Координаты вручную задавать не требуется. Экспорт — дополнительная возможность переноса точек в поле Initial points другой ноды. Сохранённые визуально точки имеют приоритет над Initial points.

Для действия на нажатие добавьте **При взаимодействии с 3D / On 3D Interaction** в Sheet Blueprint того же документа. Укажите ID окна и ID точки, выберите `click` и подключите нужные действия. `hover` срабатывает при наведении, `leave` — при уходе, `place` — при размещении. Пустой ID точки принимает события всей модели и любых её точек. Выходы передают ID, текст, имя объекта и координаты.

**На весь экран** разворачивает просмотр поверх Foundry; Escape возвращает окно. Ползунок **Фон** меняет непрозрачность: 0 — прозрачный, 1 — сплошной. Эти параметры также доступны в ноде открытия и **Настройки показа 3D**.

## Ноды

| Русское название | English / type | Назначение |
| --- | --- | --- |
| Показать 3D-модель | Show 3D Model / `model3d_open` | Загружает GLB или glTF в изменяемое по размеру окно |
| Показать 3D-фигуру | Show 3D Primitive / `model3d_primitive` | Куб, сфера, цилиндр или тор; цвет и фон |
| Трансформация 3D-модели | Transform 3D Model / `model3d_transform` | Абсолютные X/Y/Z, повороты в градусах, единый положительный масштаб |
| Анимация 3D-модели | Control 3D Animation / `model3d_animation` | Запуск, пауза, остановка встроенного клипа; имя/индекс с нуля, скорость |
| Сброс 3D-камеры | Reset 3D Camera / `model3d_reset` | Вписывает всю модель в окно после трансформации |
| Закрыть 3D-окно | Close 3D Viewer / `model3d_close` | Закрывает окно и освобождает GPU-ресурсы |
| Задать точку 3D | Set 3D Point / `model3d_hotspot` | Создать, обновить или удалить точку из графа |
| Настройки показа 3D | 3D Display Settings / `model3d_display` | Полноэкранный режим и непрозрачность |
| При взаимодействии с 3D | On 3D Interaction / `on_model3d_interaction` | События клика, наведения, ухода и размещения |

**ID окна** по умолчанию `model`. Одинаковый ID заменяет предыдущее окно,
разные ID позволяют открыть несколько моделей. Передавайте выход ID первой ноды
во вход ID следующих. В каждой ноде действия есть «Далее», «Успех» и «Ошибка».
«Далее» выполняется после завершения действия, в том числе при ошибке;
для обработки ошибок подключайте «Успех» к условию ветвления.
Закрытие уже закрытого окна считается успешным.

Пример цепочки: событие → Показать 3D-модель → Трансформация 3D-модели
(поворот Y = 45) → Сброс 3D-камеры. Соедините также выходы/входы ID окна.
Трансформация задаёт все параметры: пропущенные координаты/углы равны нулю,
масштаб равен единице. Чтобы сохранить другие параметры, указывайте их явно.

## Форматы и ограничения

- Поддерживаются обычные `.glb` и `.gltf`, материалы, текстуры и встроенные анимации.
  Кнопки выбора/паузы анимации появляются только у моделей с клипами.
- Рекомендуется GLB со встроенными текстурами. Для glTF сохраняйте относительное
  расположение `.bin` и текстур. Файлы должны уже находиться в доступном каталоге
  Foundry; просмотрщик не загружает их с компьютера на сервер.
- Внешние HTTP(S)-адреса должны разрешать CORS. На HTTPS-сервере используйте HTTPS.
- Draco, Meshopt и KTX2/Basis требуют дополнительных декодеров, которые здесь
  не подключены. Экспортируйте модель без этих вариантов сжатия. OBJ/FBX не поддерживаются.
- Нужен браузер с WebGL2. Окно остаётся внутри Foundry и не открепляется
  в отдельное окно браузера. При потере графического контекста откройте просмотр заново.
- Three.js 0.180.0 включён локально с лицензией MIT и загружается только при
  первом открытии просмотра. Интернет для самого движка не нужен.
- Загрузка ограничена 60 секундами. Закрытие отменяет ожидание; если сетевой запрос
  завершится позже, полученные ресурсы будут освобождены.

Интеграция использует существующий `SDFoundryWindowHost` на основе
[ApplicationV2 Foundry v14](https://foundryvtt.com/api/classes/foundry.applications.api.ApplicationV2.html),
[GLTFLoader](https://threejs.org/docs/pages/GLTFLoader.html) и
[OrbitControls](https://threejs.org/docs/pages/OrbitControls.html).

## Проверка

`node scripts/test-3d-nodes.mjs` — компиляция графа, передача результатов,
выполнение действий, ошибки и освобождение ресурсов.

`node scripts/test-model-interactions.mjs` — сохранение/повторное открытие точек и выполнение событий.

`node scripts/run-3d-viewer-browser.mjs` — реальный WebGL, размещение точек мышью, подсказки, клики, редактирование, сохранение, удаление, полный экран и прозрачность.

`scripts/test-3d-viewer-browser.html` — браузерная проверка с настоящим Three.js/WebGL
и облегчённой оболочкой ApplicationV2. Запускается через локальный HTTP-сервер;
она не заменяет проверку в игровом мире Foundry v14.
