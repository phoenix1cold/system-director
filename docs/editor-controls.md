# Поиск и выбор файлов

В выпадающих списках интерфейса System Director теперь открывается строка поиска. Можно искать по названию или значению, включая русский текст. Enter выбирает вариант, стрелки перемещают выделение, Escape закрывает список. Отключённые варианты не предлагаются. Для списков с множественным выбором можно отметить несколько значений.

В файловых полях нод появилась кнопка папки. Она открывает [FilePicker Foundry v14](https://foundryvtt.com/api/classes/foundry.applications.apps.FilePicker.html), а выбранный файл сразу записывается в ноду. Ручной ввод пути и соединения с входами продолжают работать. Изображения, иконки эффектов, звук/музыка и GLB/glTF поддерживаются. Пути свойств документа и названия Font Awesome остаются обычными текстовыми полями.

Для новых типов нод можно явно указать `fileType: "image"`, `"audio"`, `"imagevideo"` или `"any"` в описании поля. Поля старых нод определяются по их ключу и назначению.
